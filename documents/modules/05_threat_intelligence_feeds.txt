-----------------------------------------------------------------------------------------
1. OVERVIEW & PURPOSE
-----------------------------------------------------------------------------------------
The Threat Intelligence Module ingests, normalizes, and correlates Indicators of Compromise
(IoCs) across premier open-source and commercial security telemetry networks. It provides
SOC analysts with a unified, searchable tactical threat feed categorized by CVEs, malicious
IP clusters, botnet command-and-control (C2) domains, and ransomware file hashes.

-----------------------------------------------------------------------------------------
2. INTEGRATED INTEL SOURCES & VENDORS
-----------------------------------------------------------------------------------------
1. CISA Known Exploited Vulnerabilities (KEV Catalog):
   - Ingests US Department of Homeland Security / CISA catalog of actively weaponized CVEs.
   - Example: CVE-2026-76461 (Zero-day Remote Code Execution in edge gateway controllers).
2. AlienVault Open Threat Exchange (OTX Pulses):
   - Ingests crowd-sourced threat pulses detailing active brute-force botnets (e.g., Mirai
     scanning clusters targeting IoT devices across 14 ASN blocks).
3. CertStream SSL Certificate Transparency Network:
   - Real-time RFC 6962 CT log stream monitoring newly registered lookalike domains and
     typosquats (e.g., Let's Encrypt certificates issued for spoofed Apple/PayPal portals).
4. Local SOC Sensor Mesh (eBPF Kernel Probes):
   - Internal sensor telemetry capturing lateral movement probes and SMB burst scans.
5. VirusTotal v3 Multi-AV Engine Feed:
   - Live file hash scanning aggregated across 72 antivirus engines with detailed breakdown
     of malicious vs. suspicious vs. harmless verdicts (e.g., LockBit 3.0 Ransomware).
