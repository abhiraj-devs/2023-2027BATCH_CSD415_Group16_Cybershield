**9. Objectives of the Project:**

* To develop a web-based cybersecurity monitoring dashboard that aggregates security telemetry and provides real-time alerts.
* To implement on-demand phishing-URL and malware scanning capabilities.
* To integrate the Google Gemini API to generate human-readable, expert explanations for detected threats to assist small IT teams and Security Operations Centers (SOCs).
* To bridge the gap between offline threat detection accuracy and actionable, real-time response tooling.

---

**10. A Brief Description About the Project (Max. 300 words):**  
CyberShield AI is a layered client-server web application designed to empower small IT teams and Security Operations Centers (SOCs) with accessible, real-time threat detection. Built with a React/Vite frontend and an Express.js/TypeScript backend, the dashboard aggregates security metrics and provides on-demand scanning for phishing URLs and malware. Unlike standalone detection models, CyberShield AI integrates the Google Gemini API to analyze flagged threats and automatically generate human-readable, expert explanations, making complex security alerts easily understandable. The system features real-time network monitoring, threat-intelligence feed integration, and a simulated in-memory data store that refreshes every 10 seconds. Furthermore, detected anomalies trigger automated, severity-categorized alerts pushed directly to configurable Discord or Slack webhooks, ensuring immediate visibility and actionability for security teams.

---

**11. Relevance of the Project:**  
Current research in cybersecurity often treats phishing, malware detection, and human-centered security in isolation, resulting in high detection accuracy but poor real-time applicability for human analysts. CyberShield AI directly addresses this gap. By combining heuristic scanning, live dashboard visualization, and LLM-assisted explanations, the project ensures that raw security data is immediately translated into understandable, actionable insights. This is critical for small organizations that lack the budget for enterprise-scale SOC platforms but still require robust, explainable security monitoring.
