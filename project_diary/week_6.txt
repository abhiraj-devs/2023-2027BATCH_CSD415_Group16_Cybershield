1. INDIVIDUAL CONTRIBUTIONS & MODULE DETAILS
=====================================================================================

A. VISHNU V NAIR (Roll No: 65) - MACHINE LEARNING & FEATURE ENGINEERING
-----------------------------------------------------------------------
1. Random Forest Phishing URL Classifier Development:
   - Code Placement: /train_model.py, /features.py
   - Description: Implemented a robust Random Forest classification architecture (RandomForestClassifier from scikit-learn) to identify zero-day and obfuscated phishing links based on empirical statistical traits.
   - Dataset & Training: Formulated balanced training corpora containing legitimate domain baselines and active malicious attack signatures.
   - Evaluation Metrics: Assessed model performance using accuracy, precision, recall, and F1-score with confusion matrix validation.
   - Model Persistence: Exported serialised model parameters and weights into joblib format for seamless backend inference.

2. Comprehensive 15-Feature URL Extraction Engine:
   - Code Placement: /features.py
   - Working: Designed an automated lexical and structural extractor calculating 15 distinctive features:
     * Length Metrics: Total URL length, domain/host length, path length, and query string length.
     * Structural Tokens: Dot counts, hyphens, slashes, '@' symbol occurrences, and digit distribution.
     * Subdomain Depth: Extracted root domain and calculated subdomain depth via tldextract.
     * Shannon Entropy: Custom entropy calculator detects randomized strings, obfuscation, and algorithmic domain generation (DGA).
     * Phishing Keyword Matching: Scans for high-frequency credential harvesting keywords (e.g., login, verify, banking, secure, wallet, account).
     * Security Flags: Evaluates HTTPS scheme validity, IP address hostname pattern matching, and known URL shortener service identification.

3. Threat Intelligence Feed Optimization:
   - Code Placement: /src/components/ThreatIntelView.tsx, /src/services/api.ts
   - Working: Refined indicator aggregation rules and real-time query filtering across multi-source security feeds.
