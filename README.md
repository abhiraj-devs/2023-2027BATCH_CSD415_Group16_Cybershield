# CyberShield

## Overview
CyberShield is a comprehensive cybersecurity monitoring dashboard designed to aggregate, analyze, and visualize security threats in real-time. It leverages AI to provide expert analysis on potential security incidents, helping SOC analysts and IT administrators maintain a secure environment.

## Architecture

### Frontend
*   **Framework**: React (built with Vite).
*   **Styling**: Tailwind CSS for a sophisticated, responsive, and dark-mode-optimized UI.
*   **Visualization**: Recharts for data representation, Lucide React for iconography.
*   **State Management**: React `useState` and `useEffect` for managing real-time data flow.

### Backend
*   **Framework**: Express.js (Node.js).
*   **Language**: TypeScript.
*   **Core Functionality**:
    *   API routing for dashboard metrics, threat analysis, and settings.
    *   AI Analysis engine powered by Google Gemini API.
    *   In-memory data store (simulating database persistence).

## How it Works
1.  **Data Aggregation**: The dashboard fetches metrics from internal API endpoints simulating real-world security data (Phishing, Malware, Network, Threat Intel).
2.  **AI Analysis**: When a user submits a URL for phishing analysis or a file for malware scanning, the backend runs heuristics and requests expert explanations from Google's Gemini AI.
3.  **Threat Management**: Detected threats automatically trigger alerts that are categorized by severity.
4.  **Real-time Monitoring**: The dashboard automatically refreshes data every 10 seconds to keep the security posture up to date.

## APIs Used
*   **Internal API**: Full set of RESTful endpoints serving the dashboard, scanners, network monitoring, threat intel, and alerts.
*   **External API**:
    *   **Google Gemini API (`@google/genai`)**: Provides expert security analysis and explanations for phishing URLs and threat intelligence.
    *   **VirusTotal API (Structure)**: Simulated integration for file hash malware scanning.

## SRS (Software Requirements Specification)

### Functional Requirements
1.  **Dashboard**: Display high-level system status, threat counts (phishing/malware), active anomalies, and critical alerts.
2.  **Phishing Scanner**: Analyze URLs for suspicious lexical features and receive an AI-generated risk assessment.
3.  **Malware Scanner**: Scan files by SHA256 hash or content to identify malicious signatures.
4.  **Network Monitor**: View real-time network event logs, port/protocol statistics, and bandwidth metrics.
5.  **Threat Intelligence**: View latest security advisories, CVEs, and known malicious indicators.
6.  **Alert Management**: Manage, acknowledge, and monitor security alerts generated by the system.
7.  **Settings**: Configure webhooks (Discord/Slack) and notification severity thresholds.

### Non-Functional Requirements
1.  **Performance**: The application is designed to be highly performant, with asynchronous data loading and rapid UI responses.
2.  **Scalability**: The modular structure allows for the addition of new data sources, scanners, and integrations.
3.  **Usability**: The interface follows intuitive UX patterns with clear data hierarchy, responsive design, and intuitive controls for SOC analysts.
4.  **Accessibility**: The UI utilizes high-contrast color schemes, semantic HTML, and intuitive navigation.
5.  **Maintainability**: Codebase is written in TypeScript to enforce type safety and follows modular design patterns, facilitating easy updates and debugging.
